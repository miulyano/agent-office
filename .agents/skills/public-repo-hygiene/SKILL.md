# Репозиторий публичный

Офис показывает всё, что есть в журналах: названия сессий, папки проектов, команды, суммы. Поэтому личное легко утечь через случайный скриншот или пример.

## Плейсхолдеры вместо настоящих значений

В README, `docs/`, примерах, тестах, коммитах и описаниях PR не должно быть настоящих значений.

| Что | Плейсхолдер |
|---|---|
| Домен | `https://<your-domain>` |
| SSH-алиас | `<your-host-alias>` |
| Путь на сервере | `/opt/<your-app>` |
| Домашняя папка | `/path/to/your/project` |
| GitHub-репозиторий | `<your-github-user>/<your-repo>` |
| Telegram user_id | `<your-telegram-user-id>` |
| IP-адрес | `<your-host-ip>` |
| API-ключ, токен | `<your-api-key>` |

## Скриншоты

Только вымышленные данные. Снимок реального офиса показывает названия сессий, имена проектов и траты.

Картинки README снимает `scripts/demo/shoot.sh`: он собирает вымышленные журналы (`scripts/demo/gen.py`) во временной папке и поднимает отдельный экземпляр сервера, который настоящих сессий не видит:

```bash
scripts/demo/shoot.sh                # всё
scripts/demo/shoot.sh hero menubar   # часть
```

Осмотреть каждую картинку перед коммитом: заголовки сессий, журнал справа, подписи папок, суммы.

## Проверка перед коммитом

```bash
git diff --cached | grep -inE '/Users/|/home/[a-z]|@[a-z0-9.-]+\.[a-z]{2,}|sk-[a-z0-9]{8}|ghp_'
```

Если совпадение настоящее, заменить на плейсхолдер. Журналы, файлы `stats.json` и офисы из `~/.claude/agent-office` в репозиторий не кладутся.
