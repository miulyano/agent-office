## [0.1.0] – 2026-10-30

Первый релиз.

### Added

- Пиксельный офис по этажам: кабинет руководителя, этаж на каждый отдел, холл с лаунжем. Состояние агентов (работает, думает, кофе, спит, дома) берётся из журналов Claude Code и Codex, хуки и плагины не нужны
- Все сессии за сутки в одном списке, фильтр по провайдеру, «следить за активной»
- Задача из нескольких сессий идёт одним офисом: руководители порождённых сессий сидят в кабинете родителя, агенты на общих этажах, у людей метка с номером сессии
- Этаж «Фриланс» для встроенных агентов и подписи в лаунже
- Часы в ячейке агента: сколько работает, сколько заняло, с какого времени дома, у руководителя время текущего запроса
- Деньги у каждого стола, по отделам, по сессии и за день, по ценам API
- Статистика трат и токенов по дням, моделям, папкам и часам, лимиты Codex
- Офисы папок: штат собирается из журналов и файлов агентов, «Сгенерировать офис» через `claude -p`, новый агент садится сам
- Три вида офиса и время суток
- Скриншот здания целиком в PNG со смешным названием
- Приложение для строки меню macOS: траты за сегодня, лампочка «кто-то работает», окошко с вкладками, автозапуск
- Версии: файл `VERSION`, этот чейнджлог и релизы GitHub по тегу `v*`
